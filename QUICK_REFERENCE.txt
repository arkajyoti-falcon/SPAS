┌─ WHAT GETS EXTRACTED ───────────────────────────────────────────────────────────┐
│                                                                                  │
│  1. FILE METADATA                                                              │
│     • Filename, units (meters/inches), unit codes                              │
│                                                                                  │
│  2. SYSTEM TYPE DETECTION (Automatic)                                          │
│     CBS Type:      12K_CHUTE | 20K_LOOP | STANDARD                            │
│     Induction:     AUTO | MANUAL | MIXED | UNKNOWN                            │
│                                                                                  │
│  3. SYSTEM FEATURES (Present/Absent Checks)                                    │
│     ✓ Auto Induction       - Automated item feeding                           │
│     ✓ Operator Stations    - Manual sorting workstations                      │
│     ✓ VDS System           - Vertical diverters (qty tracked)                 │
│     ✓ Bag Takeaway         - Automated bagging/packaging                      │
│     ✓ Recirculation        - Re-feed capability                               │
│     ✓ Scanner System       - Barcode/weight readers                           │
│                                                                                  │
│  4. COMPONENT CATEGORIZATION                                                   │
│     Conveyors:       Infeed, Main, Buffer, Curve, Merge                       │
│     Output:          Chutes, Bags, Recirculation                              │
│     Induction:       Sorters, Baggers, Operator Stations                      │
│     Systems:         VDS, Scanners, Uncategorized                             │
│                                                                                  │
│  5. COMPONENT QUANTITIES                                                       │
│     Count by category | Count by specific component | Total components        │
│                                                                                  │
│  6. CHUTE ANALYSIS                                                             │
│     Total chutes | Types (collection, rejection, direct) | Per-zone breakdown │
│                                                                                  │
│  7. RAW DXF BLOCKS                                                             │
│     All block names as they appear in DXF file | Occurrence count             │
│                                                                                  │
│  8. JSON EXPORT                                                                │
│     Saved to: OUTPUT/DXF Upload/extractions/{filename}_extraction.json        │
│                                                                                  │
└──────────────────────────────────────────────────────────────────────────────────┘

┌─ HOW DATA FLOWS ────────────────────────────────────────────────────────────────┐
│                                                                                  │
│   DXF File                                                                     │
│      ↓                                                                         │
│   Extract DXF Components (categorize all blocks)                               │
│      ↓                                                                         │
│   DXF JSON Data                                                                │
│      ├─→ System Description (creates technical specs)                          │
│      ├─→ BOM Generator (equipment list)                                       │
│      ├─→ Proposal Generator (component counts)                                │
│      ├─→ Process Flow AI (understands architecture)                           │
│      └─→ Consistency Audit (validates quality)                                │
│      ↓                                                                         │
│   Proposal Documents                                                           │
│                                                                                  │
